# Audit records

Historical documents, kept for context. **Don't treat them as current.** `CLAUDE.md` and `ARCHITECTURE.md` at the repo root are what's true now.

- `JUN-5-audit-report.md`: the code audit as of **2026-11-08**. Line numbers, file names and findings describe that day's code. Many findings have since been fixed (JUN-22, JUN-45, JUN-23).
- `prompts/`: the agent prompts that drove the fix-up work (JUN-22 security, JUN-45 scalability and quality, JUN-23 agent workflow). They're useful as templates for large multi-PR efforts (owner decisions up front, a "what changed since" section, stop conditions), not as instructions to follow again.
